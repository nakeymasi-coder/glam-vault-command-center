Welcome to The Glam Vault

Settings & Help

Where your records are saved

Records are saved in this browser's local storage, on this device only. That means:

• Records do not sync between your phone, laptop, and other devices or browsers.
• Clearing browser data, or using a private window, can remove them.
• This is not a shared member submission system. Members cannot submit into this app. A shared system would need a working backend with sign-in and access controls, which this app does not have.
• Private requests and private instructor notes stay in this browser. There are no service credentials in this app; any future integration must keep credentials server-side.
• File picks save file names only — never the file contents.

Back up regularly: export a copy and keep it somewhere safe.

What this app does not do

Submitting a form, changing a status, or clicking Prepare in Chat does not access Skool, reply to members, publish posts, schedule events, or generate images or videos. Only features that have been built and tested are shown as working. Drafts, submitted requests, and verified published work are always labeled separately.

Community rules built into every prepared prompt

• Read the actual thread before preparing a contextual reply.
• Check for existing replies to avoid duplicates.
• Use the correct community context.
• Preserve supplied facts, wording, prices, dates, and links exactly.
• Flag decisions involving fees, refunds, prizes, membership, access, or deletion for Glam to decide.
• Never invent promises, testimonials, results, or completed work.
• No automatic posting and no background monitoring.
• For photo-reference challenges, preserve identity, adult age, skin tone, body size, and natural proportions.
• Warm, direct, natural voice. No repetitive praise, clichés, exaggerated promises, or profanity in business copy.

Quick help

1. Save a request in Community Intake, or fill in a Specialist Form.
2. Open the Queue. Set the status and next action.
3. Tap Prepare in Chat, review the card, and tap Copy Complete Prompt.
4. Paste the prompt into chat with your assistant. Upload any listed attachments separately — copying a prompt never transfers files.
5. For work hours, pick requests on the Work Hours screen, order them, and save the session.
6. After you truly publish something yourself, come back and set Publication to Published and verified with the live link and verification date.
